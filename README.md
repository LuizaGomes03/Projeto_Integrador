# Domínio Químico - Projeto Integrador

Projeto integrador em **React**, **React Native**, **Node.js** e **Next.js**.

## 📁 Estrutura do Projeto

```
Projeto_Integrador/
├── frontend/                    # Next.js + React (Seu domínio)
│   └── domino-quimico/
│       ├── app/
│       ├── public/
│       └── package.json
│
├── backend/                     # Node.js + Express (Domínio do back-end)
│   ├── src/
│   │   └── index.js
│   ├── .env.example
│   └── package.json
│
└── mobile/                      # React Native (Futuro)
    └── (será desenvolvido)
```

## 🚀 Como Rodar

### Frontend (Next.js)
```bash
cd frontend/domino-quimico
npm install
npm run dev
```
Acesso: `http://localhost:3000`

### Backend (Node.js + Express)
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```
Acesso: `http://localhost:3001`

## 📱 Stack Tecnológico

- **Frontend:** React, Next.js, TypeScript, Tailwind CSS
- **Mobile:** React Native (futuro)
- **Backend:** Node.js, Express
- **Versionamento:** Git + GitHub Desktop
